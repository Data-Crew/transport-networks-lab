# transport-networks-lab

Basic network science course focused on the analysis and modeling of transportation systems using Python and graph theory tools.

## Data

The `Data/` directory is intentionally kept empty in this repository. You can download the required datasets from:

📁 **[Google Drive - Data Folder](https://drive.google.com/drive/folders/1oKGjIH9EXtH8uhz7oY-vHHgjPw7ST3vU?usp=sharing)**

Once downloaded, place the contents in the `Data/` directory to run the notebooks.
